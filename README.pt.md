# SIGEVS-O

**Uma Ontologia de Domínio para Gestão de Emergências Veterinárias**

SIGEVS-O é uma ontologia de domínio fundamentada em UFO para gestão de eventos sanitários veterinários, modelada em OntoUML e desenvolvida seguindo a metodologia SABiOx. Compreende 31 conceitos organizados em quatro subdomínios, 31 axiomas formais e 36 questões de competência.

## Estrutura do Repositório

```
sigevs-o/
├── ontology/                  # Ontologia OWL/gUFO (Turtle)
├── conceptual-model/          # Modelo conceitual OntoUML (Mermaid)
├── competency-questions/      # 36 questões de competência
├── axioms/                    # 31 axiomas formais
├── sparql/                    # Queries SPARQL representativas verificadas
├── sabiox-artifacts/          # Artefatos da metodologia SABiOx
├── visual-paradigm/           # Arquivo de projeto Visual Paradigm
├── scripts/                   # Scripts de validação (popular, reasoner, consultas)
└── figures/                   # Diagramas gerados
```
