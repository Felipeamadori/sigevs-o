## Structure

- `en/` — English version
- `pt/` — Portuguese version

Each file contains a table with:
- **ID** — Competency question identifier
- **Question** — The competency question text
- **Path in the Model** — OntoUML traversal path to answer the question
- **Implementation** — JPA, PostGIS/GeoSPARQL, or SPARQL
