# SABiOx Artefacts

Ontology engineering artefacts produced during the development of SIGEVS-O following the SABiOx methodology.

## Structure

- `en/` — English version
- `pt/` — Portuguese version (original)

### Phases

| Phase | Directory | Contents |
|-------|-----------|----------|
| Requirements | `01-requirements/` | Purpose, domain, elicitation, subdomains, specification document |
| Setup | `02-setup/` | Reference ontology premises, conceptualization criteria |
| Capture | `03-capture/` | Concept catalog, axioms, OntoUML model, model documentation |

## Methodology

[SABiOx](https://doi.org/TODO) is an agile extension of the SABiO method for ontology development, grounded in UFO and expressed in OntoUML.
