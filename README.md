# SIGEVS-O

**A Domain Ontology for Veterinary Emergency Management**

SIGEVS-O is a UFO-grounded domain ontology for veterinary sanitary event management, modelled in OntoUML and developed following the SABiOx methodology. It comprises 31 concepts organised in four subdomains, 31 formal axioms, and 36 competency questions.

## Repository Structure

```
sigevs-o/
├── ontology/                  # OWL/gUFO ontology (Turtle)
├── conceptual-model/          # OntoUML conceptual model (Mermaid)
├── competency-questions/      # 36 competency questions
├── axioms/                    # 31 formal axioms
├── sparql/                    # Verified SPARQL queries
├── sabiox-artifacts/          # SABiOx methodology artefacts
├── visual-paradigm/           # Visual Paradigm project file
├── scripts/                   # Validation scripts (populate, reason, query)
└── figures/                   # Generated diagrams
```
