# Visual Paradigm

OntoUML conceptual model project for SIGEVS-O.

## Files

| File | Description |
|------|-------------|
| `SIGEVS-O.vpp` | Visual Paradigm project file |
| `SIGEVS-O-modelo-completo.jpg` | Exported complete model image |

## How to Open

1. Open Visual Paradigm (≥ 17.0)
2. File → Open Project → select `SIGEVS-O.vpp`
3. The project contains the OntoUML model with UFO stereotypes

## OntoUML Plugin

The model uses the Visual Paradigm OntoUML plugin for:
- Validating UFO stereotype assignments
- Verifying anti-patterns (FreeRole, RelRig)
- Exporting `ontouml-schema.json` for interoperability
