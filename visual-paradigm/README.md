# Visual Paradigm

OntoUML conceptual model project for SIGEVS-O.

## Files

| File | Description |
|------|-------------|
| `SIGEVS-O.vpp` | Visual Paradigm project file (final model: 33 elements, 31 relations, 10 generalizations, 1 generalization set) |
| `SIGEVS-O.json` | ontouml-schema serialization exported by the OntoUML plugin |
| `SIGEVS-O - Modelo completo.jpg` | Exported complete model image (older layout) |

The model passes the OntoUML plugin's **Check Model** with no errors. The gUFO export of the same model is `../ontology/SIGEVS-O.ttl`.

## How to Open

1. Open Visual Paradigm (≥ 17.0)
2. File → Open Project → select `SIGEVS-O.vpp`
3. The project contains the OntoUML model with UFO stereotypes

## OntoUML Plugin

The model uses the Visual Paradigm OntoUML plugin for:
- Validating UFO stereotype assignments
- Verifying anti-patterns (FreeRole, RelRig)
- Exporting `ontouml-schema.json` for interoperability
